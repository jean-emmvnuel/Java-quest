# Java Quest — guide du logo

## L'idée
Le point-virgule `;` termine chaque instruction Java : c'est le premier signe que l'élève apprend à écrire.
Ici, il devient un petit personnage curieux qui regarde vers l'avant, le compagnon de la quête.

## Typographie
Mot-symbole en **Fredoka Bold** (licence SIL Open Font, utilisable pour un logo), vectorisé : aucun texte « vivant » dans les fichiers.

## Règles
- **Zone de protection** : laisser autour du logo au moins la hauteur de la tête du personnage.
- **Tailles minimales** : symbole 16 px (avec la version petite taille sous 24 px) ; logo horizontal 100 px de large.
- **Fonds** : blanc ou très clair pour la version couleur ; version blanche sur le Bleu Bit ou sur fond sombre.
- **À éviter** : déformer, pivoter, changer les couleurs, ajouter une ombre ou un dégradé, séparer la tête du corps, retirer les yeux.

## À faire avant un usage public
Faire vérifier la disponibilité du nom et du logo auprès d'un spécialiste des marques (recherche d'antériorité).
